Reduce courier return rates (RTO) by up to 50% with instant automated phone calls powered by BTRC-approved IP phone numbers and smart IVR in Bangladesh.

---

## 🚀 Key Features

* **Instant Auto-Dialing:** As soon as an order is placed on your WooCommerce store, PingoLine dials the customer's phone number automatically.
* **Interactive IVR (Press 1 or 2):** Customers press **1** on their dial pad to confirm the order or **2** to cancel.
* **Real-time Order Status Updates:** WooCommerce order status transitions automatically (e.g., to *Processing* or *Cancelled*).
* **Smart Retry Engine:** Automatically retries busy, unanswered, or unreachable phone numbers according to your custom schedule.
* **Bangladeshi BTRC Telephony Integration:** Backed by [PingoLine IP Phone Service BD](https://pingoline.com) with crystal-clear voice clarity and low calling rates.

## 🛠️ Installation

1. Download the latest `pingoline-order-confirm.zip` release or install via your [PingoLine Customer Portal](https://pingoline.com/login).
2. In WordPress Admin, navigate to **Plugins > Add New > Upload Plugin**, choose the ZIP file, and click **Activate**.
3. Go to **WooCommerce > Settings > PingoLine Order Call**:
   * Enter your **API URL** (`https://pingoline.com`) and **API Token** from the [PingoLine Developer Portal](https://pingoline.com).
   * Copy the generated Webhook URL and paste it into your PingoLine webhook settings.
4. Run a connection test and start verifying orders automatically!
